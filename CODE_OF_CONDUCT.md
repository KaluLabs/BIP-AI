# Code of conduct

BIP-AI contributors are expected to keep collaboration professional, constructive, and focused on the work.

## Expected behavior

Treat other contributors with respect. Give technical criticism about ideas and implementations rather than people. Assume good faith while still asking for evidence, tests, and clear reasoning. Respect privacy and do not expose another person's private information, credentials, communications, or security reports.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate intimidation, sexualized harassment, doxxing, credential disclosure, publishing private security reports, or sustained disruption of project collaboration are not acceptable.

## Enforcement

Project maintainers may edit or remove harmful content, close or lock discussions, reject contributions, or restrict participation when necessary to protect contributors and the project.

For conduct concerns that include sensitive information, use the private security/contact route described in [SECURITY.md](./SECURITY.md) rather than posting sensitive details publicly.
