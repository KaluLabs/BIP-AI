# BIP-AI v0.1.0

Initial standalone release of **Building in Public AI**.

BIP-AI turns real project activity into evidence-backed, privacy-aware building-in-public drafts while keeping credentials and external publishing authority outside the editorial agent.

## Highlights

### Evidence-first project activity

- portable `ProjectEvent` records
- local SQLite state
- deterministic event fingerprinting and deduplication
- storyworthiness scoring
- filesystem inbox and local Git capture
- project registry
- transport-neutral real-world activity ingestion

### Privacy and editorial integrity

- `PASS / REVIEW / BLOCK` privacy gates
- traceable StoryBrief generation
- source-bound claim provenance
- immutable campaign versions
- exact `version + contentHash` approval binding
- automatic invalidation of stale approvals after edits

### Drafting

- deterministic zero-provider writer
- X thread and LinkedIn narrative drafts
- provider-neutral guarded drafting interface
- OpenAI-compatible provider adapter
- external-provider privacy gating
- unsupported-claim rejection and deterministic fallback

### Personal Access Gateway integration

- least-privilege PAG actor client
- `x.threads.create` handoff
- `linkedin.posts.create` handoff
- content-bound idempotency
- approval/action reconciliation
- fail-closed behavior on PAG denial or failure

### Control Room

- localhost-first API and web dashboard
- projects, events, campaigns, versions, and claim provenance
- draft editing/regeneration
- campaign approval
- X/LinkedIn handoff controls
- content activity calendar

### Real-world and WhatsApp boundary

- deliberate hardware, device, physical-task, deployment, and meeting signals
- sanitized external update contract
- no WhatsApp phone/JID/session credentials in BIP-AI state
- deterministic hashed source references for message deduplication
- approved-content export contract for a separate WhatsApp Status Manager

### Project and release hardening

- Apache License 2.0
- SECURITY, CONTRIBUTING, CODE_OF_CONDUCT, CODEOWNERS
- issue and pull-request templates
- Dependabot configuration
- release/dependency policies
- security/trust-boundary ADRs
- self-hosted CI on Node.js 22+
- `actions/checkout` v7.0.1 pinned to its immutable official commit
- historical exposure audit across retained development history, with later release-hardening commits scanned separately

## Installation and use

BIP-AI requires Node.js 22.5 or newer.

```bash
npm test
node ./src/cli.js event emit ./examples/project-event.json
node ./src/cli.js campaigns list
node ./src/cli.js serve
```

The package remains marked `private: true`; v0.1.0 is a source release and is not being published to npm.

## Security model

BIP-AI does not own X, LinkedIn, or WhatsApp publishing credentials. Publishing requests are delegated through PAG, and external transports remain separate adapters.

The Control Room is localhost-first. Remote binding is an explicit opt-in and is not itself an authentication mechanism.
